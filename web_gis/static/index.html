Salient Features & Operational Instructions

1. Feeder GIS Map & Line Tracing

Plot primary 11kV trunk feeders and branch DT networks using real pole GPS coordinates. Lines are drawn using constrained Minimum Spanning Tree (MST) algorithms to reflect physical street spans (≤120m). Use the Multi-Feeder HUD checkboxes to select and plot multiple feeders simultaneously. Supports map rotation (↺, ↻, reset North) and toggle between direct poles and high-density clustering.

2. Electrical Single Line Diagram (SLD)

Visualizes the complete utility electrical hierarchy from Grid Substation down to DT branches. Click on any Distribution Transformer (DT) card to open an instant modal with the full connected consumer schedule, showing CA numbers, meter numbers, sanctioned loads, and pole linkages.

3. Consumer Database & CSV Export

Comprehensive directory of 136,355 consumers with multi-attribute filtering by Zone, Grid, Trunk, Sub Feeder, DT, and Tariff Segment (Domestic, Commercial, Industrial). Provides fast text searching and a streaming CSV export that includes exact Latitude & Longitude for all filtered rows.

4. Outage & Maintenance Simulator

Select any feeder or transformer node to simulate an upstream breaker trip or planned shutdown. Instantly calculates impacted downstream consumers, unserved load (kW), and identifies critical consumers (HRB, Commercial) to streamline maintenance planning.

5. Executive Network Analytics (5th Icon)

Dedicated dashboard comparing Zone 515 and 518 operational profiles, category-wise load distributions, feeder length metrics, and top loaded distribution transformers.

6. Google Earth KML Export

Download plotted feeder routes directly as standard KML files using the download button at the bottom of the left dock. Easily importable into Google Earth Pro for 3D geospatial terrain analysis.
